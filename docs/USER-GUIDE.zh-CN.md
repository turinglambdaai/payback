# Payback 使用指南

[English](USER-GUIDE.md) · **简体中文**

记录已有设备的每日成本，以及你赋予使用它们的价值。

## 当前可用状态

Payback 的定位是已交付平台全部免费。旧限制移除尚待完成；不销售 Pro 授权。

## 平台与安装

提供 macOS、Windows、Linux 桌面预览版；移动端尚未交付。

从[官方 Releases](https://github.com/turinglambdaai/payback/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 添加示例设备，填写购买价格、币种和日期。
2. 可设置每天愿意付出的价值，核对单个设备计算；这属于个人估算，不是投资收益。
3. 重新打开应用确认保存结果，再录入完整设备库或启用共享文件夹。

## 数据、备份与恢复

退出全部写入进程后，备份完整应用数据目录；启用同步时同时备份整个同步目录。当前 v2 同步使用每台机器的 JSON 分片与删除标记，不是一个权威 payback.json。local.json 仅属于本机。先在副本验证恢复，再重新连接同步。

## 联网、密钥与隐私

本地记录不需要 Payback 账号。交给同步服务的文件夹会由该服务处理；更新检查和发行包下载也会联网。

## 已知限制

已有构建仍可能执行旧版十设备/PB1 限制（#20）。跨币种汇总目前不可靠（#23），请保持同一币种并核对单设备金额。GTK 日期输入存在已知 ISO 日期缺陷（#22）。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turinglambdaai/payback/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。

[敏感漏洞请按 SECURITY.md 的私下流程报告](../SECURITY.md)。
